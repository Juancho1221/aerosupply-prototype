AeroSupply Core es una solución web para centralizar y estandarizar el ciclo de abastecimiento de partes aeronáuticas. Desarrollada como prototipo funcional para las historias de usuario HU-001 y HU-002, permite el levantamiento de requerimientos técnicos en hangar con validación reactiva, alertas operativas para urgencias AOG, control estricto de duplicados y seguimiento de envíos con panel de detalles logísticos.
